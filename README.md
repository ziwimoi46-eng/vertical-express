# Vertical Express Elevators

A modern, responsive React + Vite web application showcasing Vertical Express Elevators Pvt. Ltd. — an ISO 9001:2015 certified elevator engineering, manufacturing, installation, and maintenance company based in Chhatrapati Sambhajinagar, Maharashtra.

## Key Features

- **Company Showcase & Hero Section**: Brand positioning, certified ISO 9001:2015 credentials, and vertical mobility engineering focus.
- **Service Catalogue**: Detailed elevator solutions including Auto Door Lifts, Glass Door Lifts, Capsule Lifts, Hydraulic Lifts, Swing Door Lifts, Car Lifts, Hospital Lifts, and Goods Lifts with high-resolution imagery and direct inquiry CTAs.
- **Leadership & Gallery**: Director profiles (Quazi Tafazzuluddin, Mohd Shoeb) with academic and engineering credentials, team showcase, and an interactive full-screen photo gallery lightbox with keyboard and touch navigation.
- **Direct Inquiry Engine**: Multi-channel enquiry flow allowing clients to compose structured quotes and launch pre-filled direct enquiries via WhatsApp and Email.
- **Responsive Architecture**: Built with React 19, Vite, Tailwind CSS v4, Lucide icons, and Wouter for smooth routing.

## Development

```bash
# Install dependencies
npm install

# Start local development server (port 3000)
npm run dev

# Type check
npm run lint

# Production build
npm run build
```
